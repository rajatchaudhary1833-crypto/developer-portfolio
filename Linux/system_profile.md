## 2. Binary Number Representation

### A. Decimal 75 to Binary

Divide the number by 2 and write the remainder.

75 / 2 = 37 remainder 1
37 / 2 = 18 remainder 1
18 / 2 = 9 remainder 0
9 / 2 = 4 remainder 1
4 / 2 = 2 remainder 0
2 / 2 = 1 remainder 0
1 / 2 = 0 remainder 1

Read the remainders from bottom to top.

Answer: (75)10 = (1001011)2

### B. Binary 110101 to Decimal

Using positional weight method:

110101

= (1 x 2^5) + (1 x 2^4) + (0 x 2^3)
  + (1 x 2^2) + (0 x 2^1) + (1 x 2^0)

= 32 + 16 + 0 + 4 + 0 + 1

= 53

Answer: (110101)2 = (53)10

### C. Why Computers Use Binary

Computers use binary because electronic circuits can easily
represent two states: ON (1) and OFF (0).
